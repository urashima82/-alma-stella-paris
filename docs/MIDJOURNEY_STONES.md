# Prompts Midjourney — Pierres Alma Stella Paris

> Prompts pour générer les photos de chaque pierre naturelle utilisée dans les
> bijoux Alma Stella Paris. Toutes les images sont au ratio **1:1** et respectent
> la charte graphique de la marque.

---

## Cohérence avec la charte

| Élément | Directive |
|---|---|
| **Fond** | Warm white (#FAF8F4) ou linen (#F0EBE1) — jamais de fond froid |
| **Lumière** | Dorée, naturelle, diffuse — jamais froide ni artificielle |
| **Accessoires** | Fleurs séchées, lin, céramique, bois — vocabulaire visuel de la marque |
| **Ambiance** | Intime, éditoriale, chaleureuse — jamais corporate ni agressive |
| **Pont Paris–Mexique** | Éléments naturels organiques, couleurs terre, soleil |

## Paramètres communs

| Paramètre | Valeur | Raison |
|---|---|---|
| `--ar 1:1` | Carré | Format uniforme pour le site |
| `--s 750` | Stylisation haute | Rendu éditorial raffiné |
| `--v 6.1` | Version récente | Meilleur photoréalisme |

> Ajuster `--s` entre 500–1000 selon le niveau d'interprétation artistique
> souhaité, ou ajouter `--q 2` pour une qualité supérieure.
